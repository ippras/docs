# Eicosapentaenoic and docosahexaenoic fatty acids

<!-- i18n:skip -->
$$20:5[\omega-3] + 22:6[\omega-3]$$

## Abbreviations

- EPA + DHA

## Description

Represents the sum of EPA and DHA content, which are essential omega -3 fatty acids.
